# TradingView ICT indicators (Pine Script v5)

| File | Description |
|---|---|
| `ict_toolkit_all_in_one.pine` | **All ICT tools in one indicator**, each switchable in Settings. |
| `ict_order_blocks.pine` | Order blocks only. |
| `ict_fair_value_gap.pine` | Fair value gaps only. |

## How to add to TradingView
1. Open a chart, then **Pine Editor** at the bottom.
2. Delete the template code and paste the whole contents of the `.pine` file.
3. Click **Save**, then **Add to chart**.

The free TradingView plan allows only a few indicators per chart, so use the toolkit on its
own (it already includes the order blocks and FVGs).

## What the toolkit includes
1. **Market structure**: BOS / MSS (CHoCH).
2. **Order blocks and breaker blocks.**
3. **FVG, inversion FVG (IFVG), BPR and volume imbalance (VI).**
4. **Liquidity**: BSL / SSL, EQH / EQL and sweeps (stop raids).
5. **Premium / discount, equilibrium, OTE 62–79% (70.5%) and -0.27 / -0.62 / -1 / -2 targets.**
6. **Killzones** (Asia, London, NY AM, NY Lunch, NY PM), **Silver Bullet** and **macros**, all in New York time.
7. **Levels**: PDH/PDL, PWH/PWL, PMH/PML, IPDA 20/40/60, midnight open, 08:30 open, weekly open.
8. **Opening gaps**: NWOG / NDOG.
9. **Displacement candles.**
10. **SMT divergence** against a correlated market.
11. **Dashboard and alerts.**

These are analysis tools only, not financial advice.
